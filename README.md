# 🎓 Cloud Student Attendance System

A web-based Cloud Student Attendance System that helps teachers manage student information, record daily attendance, and monitor attendance statistics through a simple dashboard.

## 📌 Features

* 👨‍🎓 Add and manage student details
* 🔍 Search students
* 🗑️ Delete student records
* ✅ Mark students as Present
* ❌ Mark students as Absent
* 📅 Record attendance by date
* 📋 View attendance records
* 📊 Calculate attendance percentage
* 📈 Dashboard with attendance statistics
* 💾 Store data using SQLite
* 🔗 Flask REST APIs
* 📱 Responsive user interface

## 🛠️ Technologies Used
